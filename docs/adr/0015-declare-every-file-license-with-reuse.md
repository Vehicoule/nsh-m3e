# 0015. Declare every file's license with REUSE, checked in CI

- Status: Proposed
- Date: 2026-11-06
- Deciders: the user

## Context

The user agreed on 2026-11-06 to check that every file has its license declared. The library is `MPL-2.0`
([ADR 0007](0007-license.md)); vendored files keep their own license (`reference/README.md`,
`.claude/skills/PROVENANCE.md`): Apache-2.0 for the androidx files and the NSH skills, MIT for two skills, CC BY 3.0
for Google's style guide. Today nothing checks that a new file, vendored or not, says under which license it is.

- [REUSE](https://reuse.software/spec-3.3/), from the Free Software Foundation Europe, is a specification for
  declaring each file's copyright and license, either in a header in the file or in a `REUSE.toml` file at the root
  that covers paths. Its tool, `reuse` 6.3.0 (PyPI, GPL-3.0-or-later), fails `reuse lint` when a file has neither.
- Vendored files are never edited by hand, and `scripts/sync-androidx.sh` and `scripts/sync-nsh.sh` copy them as they
  are, so they cannot take a header.
- The token modules under `crates/nsh-m3e/src/tokens/androidx/` are generated by `cargo xtask gen-tokens` from the
  Apache-2.0 androidx files.

## Options

1. **A header in each file we write, `REUSE.toml` for vendored and generated files.** Licensing visible in every file.
   Every new file needs the header; the first pull request touches every file, while other pull requests are open.
2. **`REUSE.toml` alone, with explicit paths.** Our own paths are `MPL-2.0`, each vendored path keeps its license, the
   generated tokens are declared `MPL-2.0 AND Apache-2.0`. No file changes; a file under a path nobody listed (a new
   top-level directory, a new vendored copy) fails the check, which forces its license to be decided.
3. **No check.** Licensing stays in the ADRs and provenance files, unchecked.

## Decision

Recommended: option 2. The copyright text of our own files is "The nsh-m3e contributors", whose authors are recorded
by Git; the user confirms this wording, and the declaration of the generated tokens as carrying both licenses.

## Consequences

- `REUSE.toml` declares every path; `LICENSES/` holds the text of each license used, `LICENSES/MPL-2.0.txt` being a
  copy of `LICENSE`, which stays for GitHub's license detection.
- The `REUSE` workflow runs `reuse lint` 6.3.0 on every pull request. A vendored file added outside the declared
  vendored folders fails it; new files copied into those folders by the sync scripts are covered by their folder.
- A new top-level file or directory needs a line in `REUSE.toml`.
